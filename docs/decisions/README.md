# Architecture Decision Records

ADRs record durable decisions and the reasoning behind them.

## Format

Each ADR should include:

- Status
- Context
- Decision
- Consequences

Optional sections:

- Alternatives considered
- Follow-up work

## Naming

Use sequential names:

```text
001-capture-first.md
002-context-items.md
003-read-only-integrations-first.md
```

## Status values

Suggested statuses:

- Proposed
- Accepted
- Superseded
- Deprecated
